# Helios

A small 3D solar observatory. The Sun, eight planets, the Moon, and a quiet asteroid belt, drifting in the dark.

Drag to look around. Scroll to zoom. Click a world to fly in. Pause time, speed it up, or pull back to the whole system.

Sizes and distances are scaled so the outer worlds stay visible. The clock counts **Earth years** of simulated time.

Made by Zakaria Shagor with help of Grok AI.
